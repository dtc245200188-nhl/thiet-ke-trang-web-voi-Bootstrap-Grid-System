# Bootstrap Grid System

Bài tập thiết kế trang web responsive với Bootstrap 5 (Container, Grid System, Navbar có dropdown).

## Bố cục
- Header, Navbar (có dropdown), Main Content, Sidebar, Footer
- Desktop (≥ 992px): Main `col-lg-8` + Sidebar `col-lg-4`
- Mobile (< 992px): Main và Sidebar đều `col-12`, Sidebar nằm dưới Main

## Chạy thử
Mở file `index.html` bằng trình duyệt (cần internet để tải Bootstrap từ CDN).
